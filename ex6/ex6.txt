Ex6:
I/O Streams and Object Serialization

1.	Write a java program using byte streams to read a text file and makes an alphabetical list of all the words in that 
file. That list of words is written to another file. Improve the program so that it also keeps track of the number of 
times that each word occurs in the file. Two lists should be displayed in the output file. The first list contains the 
words in alphabetical order. The number of times that the word occurred in the file should be listed along with the word. 
Then write a second list to the output file in which the words are sorted according to the number of times that they 
occurred in the files. The word that occurred most often should be listed first.

2. Write a Java program using character stream classes that copies one file content to another, replacing all lower 
characters by their upper-case equivalents

3.You are developing a Java application that needs to process log files generated by a server. Each log file is several 
gigabytes in size and contains thousands of lines. The application should perform the following tasks:
1.	Read the log file line by line and filter out only the lines that contain the keyword "ERROR".
2.	Write the filtered lines into a new file named error_logs.txt.
3.	Ensure the solution is efficient and can handle large log files without running out of memory.
4.	The program should also provide feedback on the total number of "ERROR" lines found and written to the new file.

4. You are developing a Java application for a network monitoring system that receives serialized data packets from 
multiple sensors. The data packets contain various readings such as temperature, humidity, and pressure, and they are 
transmitted in a binary format. The data is sent over a network connection and received as a byte array. Each packet is 
serialized as an object and contains multiple fields.
Your task is to process the incoming byte arrays in the following way:
1.	Read the byte array data from the network using ByteArrayInputStream.
2.	Deserialize the data using ObjectInputStream to reconstruct the sensor readings into Java objects.
3.	Filter the data to process only packets with a temperature reading above a certain threshold (e.g., 30°C) using FilterInputStream.
4.	Store the filtered readings in a list for further analysis.

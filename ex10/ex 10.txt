JSP-based web application
1. Design a web application for Sports Event Registration using JSP, Servlet, and JDBC. Create a JSP page named sportsRegistration.jsp with a form to collect Student Name, Roll Number, Department, Sports Event (Cricket, Football, Basketball, Athletics), and Contact Number, and submit the form to SportsRegistrationServlet using the POST method. The servlet should read and validate the inputs, check for empty fields, ensure numeric values for Roll Number and Contact Number, and insert the information into the sports_registration table. Redirect to success.jsp on successful insertion or error.jsp on failure.
2. Write a client-server JSP program to find the simple interest and display the result to the client. (Create an HTML form for inputting the P,N, and R values. Create a JSP page that acts as a client to receive P, N, and R values. These values will be sent to the server Java program (java bean) for calculating the simple interest. The computed interest value is displayed by the JSP page.
